# DubStudio

Công cụ hỗ trợ lồng tiếng Anh → Việt: chép lời, dịch vừa khung thoại, đo độ khớp bằng giọng đọc thử, biên tập và xuất SRT cho từng diễn viên.

## Tải về

Bản mới nhất ở trang [Releases](https://github.com/kaisye/dubstudio-app/releases/latest):

- **macOS** (Apple Silicon, macOS 12+): file `.dmg`
- **Windows** (10/11, 64-bit): file `-setup.exe`

### Lần đầu mở app

- macOS: nếu máy báo không mở được, nhấp chuột phải vào DubStudio trong Applications → *Mở*.
- Windows: nếu thấy màn hình bảo vệ, chọn *Thông tin thêm* → *Vẫn chạy*.

Repo này chỉ chứa bản cài; mã nguồn không công khai.
